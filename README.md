# VpnKavkaz для Android

VPN-клиент для телефонов, планшетов и Android TV. Работает на Android 8 и новее.

## Скачать

**[Скачать VpnKavkaz 0.29-preview — универсальный APK](https://github.com/korkmasov-png/VpnKavkaz-Android/releases/download/v0.29/VpnKavkaz-0.29-preview-universal.apk)**

APK подходит для телефонов, планшетов и телевизоров с Android 8+. Во время установки Android может запросить разрешение на установку приложений из этого источника.

## Возможности

- Автоматический или ручной выбор сервера и переход к резервному серверу при сбое.
- Добавление подписок и серверов по ссылке, QR-коду или из файла.
- Автоматическое и ручное обновление подписок.
- Выбор приложений для VPN: все, все кроме выбранных или только выбранные.
- Проверка задержки серверов без отключения действующего VPN.
- Настройка DNS и защищённый резервный DNS.
- Управление из уведомления и плитки быстрых настроек Android.
- Зашифрованное хранение подписок и резервное копирование с паролем.
- Поддержка Android TV, управление пультом и перенос подписок по QR-коду.
- Журнал ошибок с возможностью отправить его разработчикам.

## Поддерживаемые протоколы

- **TUIC v5** — через sing-box: QUIC, TLS, ссылки `tuic://` и персональные профили.
- **Hysteria2** — QUIC и TLS.
- **VLESS** — REALITY, XHTTP/CDN и профили подписок VpnKavkaz.
- **VMess** — TCP, WebSocket и gRPC, с TLS и без него.
- **Trojan** — подключение через Xray с проверкой TLS.
- **Shadowsocks** — AEAD, Shadowsocks 2022, ссылки SIP002 и legacy.
- **WireGuard** — JSON, `.conf` и ссылки, TCP- и UDP-трафик.
- **SOCKS5** — с поддержкой имени пользователя и пароля.

Поддержка конкретных параметров зависит от формата профиля. Неподдерживаемые или небезопасные настройки не применяются скрытно: приложение сообщает об ошибке.
